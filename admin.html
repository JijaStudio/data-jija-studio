Image & video URL converter

Upload an image or video once to Jija Studio media storage. The tool will create a reusable HTTPS URL you can copy into product images, product videos, homepage banners, collection cards, or other URL fields. This stores the original file in Firebase Storage instead of turning it into a huge text string.

Images: JPG, PNG, WebP, GIF. Videos: MP4 or WebM recommended. Keep uploads under 50 MB for reliable uploads.
Leave blank to use the original file name.
Choose a file to get started.

Note: generated URLs are shareable by anyone who has the link. If upload permission is denied, Firebase Storage rules must allow signed-in admin uploads.
