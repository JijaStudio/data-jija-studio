The intended payment options are UPI and payment links. Use only payment details confirmed by the store. The displayed UPI ID is a placeholder, and this demo does not verify payments.

Can I check delivery by PIN code?

The current form checks that a PIN code contains six digits. It does not query a courier or postal database, so actual delivery coverage must be confirmed separately.
